# Contributing to Flutter IoT SDK

Thank you for your interest in contributing to `flutter_iot`!

## Code Contributions

1. Fork the repository and create your feature branch.
2. Ensure your changes follow the Dart lint rules (`analysis_options.yaml`).
3. Add unit tests in `test/` for new functionality.
4. Verify tests pass using `flutter test`.
5. Verify example app builds and passes linter with `flutter analyze`.
6. Submit a Pull Request with a clear description of your changes.

## Bug Reports & Feature Requests

Please open an issue on GitHub describing:
- Detailed steps to reproduce.
- Target platform (Android, iOS, Web, Windows, macOS, Linux).
- Relevant stack trace or diagnostic log output (`IoTLogger`).
